# BERT 原版代码文件导览

原有 21 个文件与 [google-research/bert](https://github.com/google-research/bert) 的顶层文件清单一致（核对日期：2026-10-12）。为运行论文中的 11 项下游任务，本目录另增加任务、评估与记录文件。脚本用同目录模块导入；保持原目录布局。

## 新增的论文实验文件
- `run_experiment.py`：11 项任务的统一入口，按任务创建编号运行目录并记录命令、代码状态和结果，调用run_classifier.py进行BERT训练和评估，如果训练已经成功，再用测试集进行评估的时候出现错误，后面不用再进行训练，只要重新进行评估，只要运行run_classifier.py就可以同时要给出我们实验参数，do_train设置成False。
- `run_swag.py`：SWAG 四选一续写任务的训练、开发集评估和测试预测。
- `task_metrics.py`：GLUE 的任务指标及 SQuAD 的 EM/F1 计算。
- `experiment_utils.py`：保存完整参数和数据相关的实际训练步数。
- `运行11项任务.md`：数据组织、运行命令、输出结构和论文结果对照说明。
- `requirements-paper-experiments.txt`：供论文实验使用的 TensorFlow 1.15 CPU 环境约束。

## 核心模块
- `modeling.py`：BertConfig、BertModel、embedding、Transformer、checkpoint 变量映射。
- `tokenization.py`：BasicTokenizer、WordPiece、词表读写及大小写与 checkpoint 匹配检查。
- `optimization.py`：AdamWeightDecay 优化器、学习率 warmup 和衰减。

## 运行入口
- `create_pretraining_data.py`：从文本生成 MLM/NSP 预训练 TFRecord。
- `run_pretraining.py`：读取 TFRecord 执行 MLM/NSP 预训练与评估。
- `run_classifier.py`：GLUE/XNLI 等分类任务的微调、评估和预测。
- `run_squad.py`：SQuAD 阅读理解的微调与答案预测。
- `extract_features.py`：从已有 checkpoint 提取各层 token 向量。
- `run_classifier_with_tfhub.py`：通过旧版 TensorFlow Hub 模块做分类微调；仅使用该路线时需要。

## 测试、示例和说明
- `modeling_test.py`、`optimization_test.py`、`tokenization_test.py`：对应核心模块的单元测试。
- `sample_text.txt`：预训练数据制作示例文本。
- `predicting_movie_reviews_with_bert_on_tf_hub.ipynb`：TF Hub 电影评论分类示例 Notebook。

## 完整性与使用边界
- 本目录是原版源码清单，不包含预训练权重、`bert_config.json`、`vocab.txt`、任务数据集或运行产物。使用相应脚本时需另行提供。
- 单纯运行基础模型时，TF Hub 脚本、Notebook、示例文本、贡献说明和单元测试可暂时不使用；它们不是错误或冗余文件。
- 代码使用 TensorFlow 1.x 风格 API（如 `tf.contrib`、`tf.flags`）。当前检查环境未安装 TensorFlow 和 tensorflow_hub，因此未执行训练或单元测试。
- 原版代码和本次增加的实验代码应结合 `run_info.json` 中的 HEAD、工作区状态及 Python 文件哈希定位实际运行版本。


## output文件解释
eval_results.txt：开发集（dev）的评估指标，例如 MRPC 的 eval_accuracy、eval_f1。

metrics.json：汇总的运行状态和评估指标。

config.json：记录实际生效的实验参数（比如batch_size，训练轮次）。这不是实验模型的参数

model.ckpt-1375.*：第 1375 步的最终训练检查点，是当前应优先保留、用于评估或推理的模型。
model.ckpt-1000.*：第 1000 步的中间检查点。
model.ckpt-0.*：全局步数为 0 时的检查点。
每个检查点的 .data、.index、.meta 是同一检查点的不同组成部分：权重数据、变量索引、图和元信息。使用时通常指定前缀，例如 model.ckpt-1375。

checkpoint：TensorFlow 的检查点索引，记录当前最新检查点是 model.ckpt-1375。

train.tf_record、eval.tf_record：由 MRPC 原始数据转换出的训练集、评估集特征文件，不是原始数据。

events.out.tfevents...：TensorBoard 事件文件，可查看训练过程记录的曲线或标量。
graph.pbtxt：TensorFlow 计算图的文本描述。

run.log：完整运行日志，包括训练进度、评估启动和最终异常。
run_info.json：运行命令、依赖版本、Git 信息、起止时间、退出码等记录。

## MRPC中的eval_results
accuracy：分类准确率，约 68.87%
accuracy_f1_mean：Accuracy 与 F1 的平均值,它可以作为比较不同 MRPC 模型版本的参考指标之一。
count:参与评估的样本数
eval_accuracy:评估准确率，与 accuracy 相同
eval_loss:评估损失，通常越小越好,用于衡量模型预测结果与真实标签之间的差异
f1:F1 分数，综合考虑精确率(Precision,模型预测为正例的样本中，实际有多少确实是正例)和召回率(Recall,所有实际正例中，有多少被模型成功找到了)
global_step:模型已经执行的训练更新步数
events.out.tfevents：使用TensorBoard可视化结果的，类似我之前学习Summarywriter，运行方式是一样的，tensboard --log="文件地址"
