# BERT 论文 11 项下游任务运行说明

本目录覆盖论文第 4 节的 11 项任务：GLUE 表中的 MNLI、QQP、QNLI、SST-2、CoLA、STS-B、MRPC、RTE，以及 SQuAD 1.1、SQuAD 2.0、SWAG。CoNLL-2003 NER 是论文第 5.3 节的另一个分析实验，不计入这里的 11 项。

## 环境和输入

1. 使用独立的 Python 3.7 + TensorFlow 1.15 环境。此源码使用 `tf.contrib`，不能直接在 TensorFlow 2.x 或当前的 Python 3.13 环境运行。CPU 环境可尝试 `python -m pip install -r requirements-paper-experiments.txt`；GPU 环境需按显卡和驱动选择兼容的 TensorFlow 1.x 构建。先确认 `python -c "import tensorflow as tf; print(tf.__version__)"` 显示预期版本。
2. 从同一个预训练 BERT 模型目录提供 `bert_config.json`、`vocab.txt` 和 checkpoint 前缀，例如 `bert_model.ckpt`。三个文件必须相互匹配；cased 模型需传 `--do_lower_case=false`。
3. 准备各任务的原始数据。代码不会自动下载数据或上传测试集预测。
4. 在 `bert-master` 目录运行以下命令。PowerShell 示例中的 `D:\models\bert_large` 和 `D:\datasets` 请替换为本机实际路径。

## 统一运行入口与结果目录

每次使用 `run_experiment.py` 运行一个任务。它会自动创建独立目录；例如第一次 MRPC 运行是：

```text
output/MRPC/MRPC-1/
├── config.json          # 实际解析后的全部参数，包含脚本默认值
├── run_info.json        # 启动时的 Git、Python、依赖、命令、时间和退出状态
├── metrics.json         # 指标、数据路径、产物与运行状态
├── run.log              # 标准输出及错误输出
├── eval_results.txt     # 有开发集评估时生成
└── ...                  # checkpoint、TFRecord、预测等
```

第二次运行将自动使用 `output/MRPC/MRPC-2/`。运行中断或失败也会保留该编号及错误记录。目录中的 `metrics.json` 不代表隐藏测试集分数；GLUE 和 SWAG 的隐藏测试标签需要各自的官方评测服务。

通用参数：`--do_train=true --do_eval=true`（SQuAD 使用 `--do_predict=true`）。如果未指定任何阶段开关，入口默认训练并评估开发集。需要生成 GLUE 或 SWAG 测试预测时，同时指定 `--do_predict=true`。训练轮数、学习率、批量大小、随机种子等可作为原脚本参数继续传入。

## 八项 GLUE 任务

把 `D:\datasets\GLUE\MRPC` 换为该任务自己的目录；目录内应有官方的 `train.tsv`、`dev.tsv`、`test.tsv`。MNLI 使用 `dev_matched.tsv`、`dev_mismatched.tsv`、`test_matched.tsv`、`test_mismatched.tsv`。

```powershell
python run_experiment.py --task MRPC --data_dir "D:\datasets\GLUE\MRPC" --bert_config_file "D:\models\bert_large\bert_config.json" --vocab_file "D:\models\bert_large\vocab.txt" --init_checkpoint "D:\models\bert_large\bert_model.ckpt" --do_train=true --do_eval=true --do_predict=true --train_batch_size=32 --num_train_epochs=3 --learning_rate=3e-5 --random_seed=42
```

其余七项使用同一命令格式，替换 `--task` 和 `--data_dir`：

| `--task` | 数据目录示例 | 开发集主要指标 |
|---|---|---|
| `MNLI` | `GLUE\MNLI` | matched、mismatched 准确率 |
| `QQP` | `GLUE\QQP` | 准确率、F1 |
| `QNLI` | `GLUE\QNLI` | 准确率 |
| `SST-2` | `GLUE\SST-2` | 准确率 |
| `CoLA` | `GLUE\CoLA` | Matthews 相关系数 |
| `STS-B` | `GLUE\STS-B` | Pearson、Spearman 相关系数 |
| `RTE` | `GLUE\RTE` | 准确率 |

`--do_predict=true` 会生成原始概率或分数 `test_results.tsv`，以及 GLUE 格式的 `submission.tsv`。MNLI 还会生成 `eval_mismatched_results.txt` 和 `submission_mismatched.tsv`。上传时按 GLUE 平台要求使用相应任务文件名。脚本不会从隐藏测试集计算指标。

## SQuAD 1.1

准备官方 `train-v1.1.json`、`dev-v1.1.json`。开发集预测后，入口读取金标准答案并将 EM/F1 写入 `metrics.json`。

```powershell
python run_experiment.py --task SQuAD1.1 --train_file "D:\datasets\SQuAD1.1\train-v1.1.json" --predict_file "D:\datasets\SQuAD1.1\dev-v1.1.json" --bert_config_file "D:\models\bert_large\bert_config.json" --vocab_file "D:\models\bert_large\vocab.txt" --init_checkpoint "D:\models\bert_large\bert_model.ckpt" --do_train=true --do_predict=true --train_batch_size=32 --num_train_epochs=3 --learning_rate=5e-5 --random_seed=42
```

## SQuAD 2.0

准备官方 `train-v2.0.json`、`dev-v2.0.json`。入口自动启用无答案样本逻辑；`metrics.json` 同时记录当前 `--null_score_diff_threshold` 的 EM/F1 和开发集扫描得到的最佳阈值及分数。论文第 4.3 节的单模型设置为 batch 48、2 epochs、学习率 5e-5。

```powershell
python run_experiment.py --task SQuAD2.0 --train_file "D:\datasets\SQuAD2.0\train-v2.0.json" --predict_file "D:\datasets\SQuAD2.0\dev-v2.0.json" --bert_config_file "D:\models\bert_large\bert_config.json" --vocab_file "D:\models\bert_large\vocab.txt" --init_checkpoint "D:\models\bert_large\bert_model.ckpt" --do_train=true --do_predict=true --train_batch_size=48 --num_train_epochs=2 --learning_rate=5e-5 --null_score_diff_threshold=0 --random_seed=42
```

## SWAG

`data_dir` 下放官方 `train.csv`、`val.csv`、`test.csv`。每行需要 `sent1`、`sent2`、`ending0` 至 `ending3`，训练和开发集还需要 `label`。目前的 SWAG 入口支持 CPU/GPU；论文第 4.4 节使用 batch 16、3 epochs、学习率 2e-5。

```powershell
python run_experiment.py --task SWAG --data_dir "D:\datasets\SWAG" --bert_config_file "D:\models\bert_large\bert_config.json" --vocab_file "D:\models\bert_large\vocab.txt" --init_checkpoint "D:\models\bert_large\bert_model.ckpt" --do_train=true --do_eval=true --do_predict=true --train_batch_size=16 --num_train_epochs=3 --learning_rate=2e-5 --random_seed=42
```

## 与论文数字对照

- GLUE 论文表 1 按每个任务在开发集选择学习率：2e-5、3e-5、4e-5、5e-5；BERT-Large 的小数据集还进行多个随机重启。请分别运行，比较各编号目录的开发集指标，再提交选定模型的测试预测。
- SQuAD 1.1 论文表 2 的最高测试分数涉及 TriviaQA 预微调及多模型集成。这些结果不能由一次 SQuAD 运行直接得到；当前入口记录单模型运行，若要复现那一行，仍需准备 TriviaQA 阶段和集成流程。
- SQuAD 2.0 的拒答阈值应在开发集选择；SWAG 的隐藏测试准确率需要官方评分。不同预训练 checkpoint、数据版本和硬件也会影响结果。
- 当前代码检查只覆盖语法与不依赖 TensorFlow 的指标计算。数据集和 TensorFlow 1.x 环境到位后，需要先运行一项任务确认完整训练链路，再逐项跑满 11 项。
