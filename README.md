建议让代码在每次运行开始时创建一个独立目录，并自动生成以下三个文件。你以后只需把这个目录路径发给我。可以给codx执行
runs/<运行编号>/
├── config.json       # 实际使用的实验参数
├── run_info.json     # 运行时的代码、环境和数据版本
└── metrics.json      # 实际结果及产物位置
各文件建议包含：
文件	需要由代码记录的内容
config.json	实验名称、数据集名称与路径、模型配置、训练参数、随机种子
run_info.json	运行开始与结束时间、完整运行命令、Git 分支、完整提交哈希、是否有未提交改动及涉及文件、Python 和关键依赖版本、运行状态
metrics.json	指标名称与数值、评估数据集或数据划分、日志与模型等产物路径；运行失败时记录错误信息


有两点尤其关键：
1. 在运行开始时采集 Git 信息，避免运行后代码变化导致版本对错。
2. 保存程序实际采用的参数，包括默认值和配置文件合并后的最终值，而不只是命令行传入的参数。
